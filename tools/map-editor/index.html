Routes et berges se raccordent automatiquement. Prévois au moins deux cases d’épaisseur pour les berges des petits plans d’eau. Clic droit : herbe ou gomme d’unité. Ctrl/Cmd + Z : annuler. Peindre de l’eau retire les unités terrestres de la case.

Proposer ta carte

  1. Donne un nom à ta carte et place une armée bleue et une armée rouge. Vérifie que les deux camps peuvent se rejoindre et accéder aux objectifs.
  2. Clique sur « Exporter le JSON » pour télécharger le fichier, ou utilise « JSON à copier ».
  3. Sur GitHub, ouvre une proposition et colle ton JSON dans un bloc de code. Ajoute le nom de la carte, ton idée de gameplay et, si possible, une capture.
Proposer sur GitHub

Les propositions sont revues avant d’être ajoutées au jeu. L’ID peut être ajusté lors de l’intégration.
